## 2. 크기 약속
- 맵: **80 × 44칸**. 1칸 = 도트 **24px**(디자인 해상도) → 바닥 그림은 **1920 × 1056 px**. 게임에서는 2배(48px/칸)로 키워 화면에 그립니다. 도트 한 개가 화면에서 2px로 보이므로 **안티앨리어싱 없는 픽셀아트**여야 합니다.
- 캐릭터는 몸 폭이 약 **1칸(24px)** 입니다. 그림을 만들 때 캐릭터 옆에 놓고 크기를 맞춰 보세요 (`reference_character_idle.png`: 256px 셀 4프레임, 발 위치 (104, 232)).
- 장애물 그림은 **투명 배경 PNG**, 기준점은 **아래쪽 가운데**(발 닿는 곳)입니다. 아래 충돌 상자(칸 단위)보다 그림이 위로 더 솟아 있어도 됩니다(캐릭터가 뒤로 지나가며 가려짐).

## 4. 강 (건널 수 없음) 과 모래 기슭
- 강 중심선: `x = 40 + 2.4·sin(0.27·y)` (구불구불), 폭 6칸(반폭 3).
- y 12~16에서 좁아져 사라지고, **y 16~28은 땅(건널목)**, y 28~32에서 다시 넓어져 y 32 이후는 6칸 폭. 위·아래 둘 다 맵 끝까지 이어짐.
- 모래 기슭: 물 바로 옆 1칸은 젖은(진한) 모래 → 마른 모래 → 점점 성기게(디더링) 잔디로 이어짐. 기슭 폭은 약 3.6칸(구간마다 ±0.45칸 다름).
- 물: 4단계 파랑(얕음 → 깊음), 물가에 흰 거품 점선, 반짝이는 점.

## 6. 게임 규칙 (디자인에 영향 주는 것)
- 두 팀이 **맵 양쪽 끝(왼쪽 x 4~6, 오른쪽 x 74~76)** 에서 시작합니다. 시작 지점 주변(약 10칸)은 비워 두세요.
- 장애물과 강은 사람도 투사체(강 제외)도 지나갈 수 없습니다. 강 위로는 투사체가 지나갑니다.
- 쓰러진 캐릭터는 **파란 유령**이 되어 천천히 움직이고, 팀원이 5초 겹쳐 있으면 부활합니다 (민트색 점선 원이 유령 발밑에 표시됨).
- 화면은 프로젝터에서 맵 전체(80×44칸)를 한 번에 보여 주므로 **작게 줄여도 구분되는 큰 형태**가 좋습니다. 폰은 약 24칸 폭만 보입니다.
