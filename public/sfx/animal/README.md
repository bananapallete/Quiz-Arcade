# 동물 울음소리 넣는 곳

여기에 실제 동물 소리 파일을 넣으면 게임이 자동으로 씁니다. 없으면 합성음으로 대신합니다.
파일 이름은 아래와 정확히 같게 (mp3 · ogg · wav 중 아무거나, 확장자만 다르면 됨):

| 파일 | 쓰는 캐릭터 | 소리 |
|---|---|---|
| dog | 강아지 · 래브라도 · 시바견 | 개 짖는 소리 (캐릭터마다 음높이를 다르게 씀) |
| cat | 고양이 | 야옹 |
| frog | 개구리 | 개굴 |
| pig | 돼지 | 꿀꿀 |
| hippo | 하마 | 하마 울음 (으르렁) |
| chicken | 닭 | 꼬꼬 · 꼬끼오 |
| chick | 병아리 | 삐약 |

권장: 길이 0.3~1.5초, 모노, 음량은 비슷하게, 앞뒤 무음 없이 잘라서. 저작권이 자유로운(CC0·퍼블릭 도메인 등) 파일만 쓰세요.
귀상어는 상어가 소리를 내지 않아서 합성음을 그대로 씁니다.
