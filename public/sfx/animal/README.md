# 동물 소리 파일

`src/sfx.js`가 자동으로 불러옵니다. 파일이 없으면 합성음으로 대신합니다. (mp3 · ogg · wav 아무거나, 확장자만 다르면 됩니다)

| 파일 | 쓰는 캐릭터 | 쓰이는 때 |
|---|---|---|
| `dog` `cat` `frog` `pig` `hippo` `chicken` `chick` | 강아지·래브라도·시바견(dog) / 고양이 / 개구리 / 돼지 / 하마 / 닭 / 병아리 | 평타(가끔) |
| `dog_ult` `cat_ult` … `chick_ult` | 위와 같은 캐릭터 | 궁극기 발동 (약 2.9초) |
| `../ult/diva1` `diva2` `diva3` | 크림슨 디바 | 궁극기 발동, 셋 중 무작위 |

- 궁극기 소리는 동시에 최대 2개까지만 재생됩니다. 넘치면 가장 먼저 시작한 소리부터 바로 꺼집니다.
- 궁극기가 끝나는 때(지속시간 · 시전자가 쓰러질 때)에는 소리가 페이드아웃됩니다.
- 올린 원본의 평균 음량이 제각각이라 mp3로 변환하면서 음량을 비슷하게 맞춰 두었습니다.
